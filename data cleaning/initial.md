Rename variables (labels from codebook
`birthorder_wages/birthorder_wages.sps`).

- `hh_yth*`: other NLSY respondents in R’s 1979 household
- `sib*`: 1993 sibling roster (`_older`: 1 = older, 2 = younger, 3 =
  twin; `_agegap` in years)
- `wage_cps_*`: hourly pay, current/most recent job; `wage_*`: hourly
  pay, job \#1
- `educ_*`: highest grade completed (revised)

NLSY missing codes: -1 refused, -2 don’t know, -3 invalid skip, -4 valid
skip, -5 non-interview. No real value in this extract is negative, so
set all of them to `NA`. Wages are stored in cents.

``` r
df <- df |>
  mutate(across(everything(), ~ if_else(.x < 0, NA, .x)),
         across(starts_with("wage"), ~ .x / 100))
```

Save the cleaned data next to the raw extract.

``` r
write_rds(df, "../birthorder_wages/nlsy_clean.rds")
```
